# LibraryReg – Aplikasi Pendaftaran Anggota Perpustakaan
Kotlin + Jetpack Compose + Room + Navigation Compose. minSdk 24, compileSdk 34.

Cara menjalankan: Android Studio (Koala / 2024.1 atau lebih baru) > File > Open > pilih folder ini > tunggu Gradle Sync > Run.
Jika sync bermasalah: buat proyek "Empty Activity" (package com.example.libraryreg), lalu salin isi folder app/src/main dan dependensi dari app/build.gradle.kts.
